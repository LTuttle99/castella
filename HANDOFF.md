# Castella handoff

Castella is NFL Attendance Intelligence & Stadium Operations Assistant, a no-login browser app that explains the supplied NFL attendance research and helps a stadium planner explore what different ticket-utilization assumptions imply for arrivals. Its deterministic assistant handles research questions and multi-turn ticket calculations, distinguishes no-show from show-up rates, retains previous scenarios, compares changes, offers professional, balanced, and fun tones, and can transfer a calculated scenario into the simulator. It also calculates illustrative staffing, concession, parking, and entry demand from editable assumptions.

The assistant uses local retrieval and deterministic response templates, not generative AI. No LLM credentials or backend are configured. The public schedule importer is implemented, but live retrieval failed in this environment because DNS/network access was unavailable. No public historical data is bundled and no historical chart is shown. The original trained research model and underlying data were not supplied, so the app cannot forecast an upcoming game. Scenario rates and operations ratios are user assumptions, not established league standards. Legacy local browser data was migrated to Castella storage keys on the same origin. The app was opened and interacted with in a browser at localhost. Static production output can be created with `python3 scripts/build.py`. It is deployed at https://ltuttle99.github.io/castella/ from https://github.com/LTuttle99/castella. The GitHub Actions deployment succeeded and the live assistant and operations page were browser-verified.

## Phase 5

The local conversation assistant replaces the inline chat response code with reusable dialogue, deterministic tools, and rendering modules. It adds conversation memory, tone-specific casual replies, numerical cards, safe scenario/navigation actions, decimal utilization transfer and reset controls. No API was added at the owner's request. There is no LLM, API gateway or external chat persistence. Phase 4 remains unmerged and historical answers are honestly unavailable on this branch. Automated evaluations cover 64 conversations / 174 turns; production is unchanged pending review.
